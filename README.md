# E-commerce Price Tracker (Web Scraper)

This project is a Python-based web scraper that extracts product listings, prices, and availability from e-commerce websites. It is designed to help businesses, e-commerce sellers, and researchers monitor competitor pricing and gather market data efficiently.

## Business Value
- **Price Monitoring:** Keep track of competitor pricing to adjust your own pricing strategy.
- **Market Research:** Understand market supply and price ranges for specific product categories.
- **Lead Generation:** Quickly gather large amounts of listing data into a structured format for analysis.

## Features
- Scrapes product titles, prices, and availability from e-commerce categories.
- Built-in command line interface (CLI) to easily change URLs and pagination limits.
- Automatically exports clean, structured data to a CSV file.
- Built entirely with lightweight libraries (`requests` and `BeautifulSoup4`).

## Tech Stack
- **Language:** Python
- **Libraries:** `requests`, `BeautifulSoup4`, `csv`, `argparse`

## How to Run

1. Clone the repository and navigate to the project directory:
```bash
git clone https://github.com/lambautroi/ecommerce-price-tracker.git
cd ecommerce-price-tracker
```

2. Install the required dependencies:
```bash
pip install -r requirements.txt
```

3. Run the script. By default, it scrapes the Science books category from our mock e-commerce site:
```bash
python scraper.py
```

4. Run with custom arguments (e.g., scraping 2 pages and saving to a custom file):
```bash
python scraper.py --pages 2 --output science_books.csv
```
